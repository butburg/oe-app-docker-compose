# Fonts

Served from our own server, never from a font CDN. License of all Figtree files: SIL Open Font License 1.1, see `Figtree-OFL.txt`.

- `figtree-latin-wght-normal.woff2`: Figtree variable font (weights 300–900), Latin subset, from `@fontsource-variable/figtree` 5.x.
  Used by the website (`resources/css/app.css`, bundled by Vite) and embedded into every HTML mail (`App\Mail\MailAssets`).
- `Figtree-Medium.ttf`: for images drawn with GD, e.g. `php artisan impressum:image` (`GenerateImpressumImage`).
